# 双人 Codex 统计版

## 设置成员和设备

在「多设备同步」中选择连接 Hub，填写 Hub URL、共享密钥、用户名和可选设备昵称。用户名会清除首尾及重复空白，以 Unicode NFC 规范化，并忽略大小写匹配；同名设备归到同一个稳定成员 ID。用户名是统计分组标签，不是独立登录账号。

同一人的多台电脑使用同名用户名，各台电脑仍须有不同的设备 ID。已有的旧版设备可以在「额度周期与成员 → 设备归属」中分配；不必删除历史数据重新注册。修改成员昵称会保留成员 ID，重新分配设备会将该设备所有保留周期归到新成员。两位持有共享密钥的使用者都能查看和调整全部成员及设备，不提供角色隔离。

## 额度周期

Hub 根据有效的 Codex Pro 主周额度窗口，使用 `resetsAt - windowMinutes` 得到开始时刻，使用 `resetsAt` 得到结束时刻。首次采用的设备和账号标识会固定为来源；其他 Pro/Plus 设备不会自动替换它。来源失效、暂时离线或重置时间过期时，Hub 保留已知周期并提示等待。需换来源时在设置中明确选择。

本轮范围为 `[start, end)`：恰好发生在结束时刻的记录属于下一轮。不是自然周，也不是始终向前滚动七天。可以手动指定起止时间，之后只有重新选择自动来源才恢复自动更新。保留最多 104 个已知周期，可在主界面选择旧周期并导出 CSV。

每台客户端获取 Hub 的周期列表后，在本地重新计算并上传汇总。两端都升级后才会出现周期数字；升级 Hub 不会从原有按天汇总数据中伪造小时级统计。新周期必须等有效的来源信息确认后才会加入列表。

## 数据口径与完整性

原生来源读取当前 `CODEX_HOME` 的 `sessions`、`archived_sessions` 和配置的额外 Codex 扫描目录，支持 JSONL 与项目原有的 Zstandard 读取限制。Windows 还会使用现有 WSL 发现逻辑读取正在运行的发行版中的标准 Codex 目录；发现结果在完整扫描时更新，普通监听刷新复用发现结果。无法访问的 WSL 数据会标为不完整；没有运行的发行版不会被主动启动。额外扫描路径应直接指向日志目录。

累计用量以原始会话标识和累计计数去重，重复的状态通知及原生/归档副本不会重复相加。按 `token_count` 的记录时间归入周期，长会话可以跨周期拆分。没有记录时间、计数回退、截断的历史前缀或中间累计缺口时，只使用能识别的明确请求增量并标为不完整，不把历史总数挪到最新日期。源日志时间不能证明请求的精确执行时刻。

本地保存只含用量事件数字、模型标识、时间和去重标识的缓存，已观察过的记录在日志删除后仍保留。启动监控之前就删除的日志不能恢复，完整状态只表示成功读取了当前可用来源，不能证明与官方账单完全一致。缓存损坏时保留既有上报，不覆盖成零。

如果已有原版 Dots 观察账本且允许显示，会按本地观察时间计入；它仍属于不完整的已观察数据，无法补回监控开启前或离线期间的请求。原生会话记录对同一线程有优先权，避免重复相加。Dots 采集默认保持原来的选择，不会自动启用实验来源。

费用按每条记录的模型、非缓存输入、缓存读取和包含推理的输出分别估价，使用原版计价目录与自定义价格。未知模型或缺失价格的 Token 显示为「未计价」，只汇总已知费用。它是 API 等价估算，不能视作订阅账单或官方额度百分比。价格目录变化可能重新计算历史估算费用。

旧版设备、未上传周期数据、无法访问的来源和离线设备不会被当成零使用量。成员/总计可能只是当前可用数据之和，展开设备可以查看最近采集时间与覆盖状态。离线不会删除已有历史。

本版不识别操作系统用户、不归属多个 Codex 账号、不跟踪账号切换，也不分摊个人可用额度。设备上所有被采集的 Codex 用量都会计入其成员。

## 界面与精简

保留原版原生玻璃、配色、透明度和字体。主界面常驻关闭按钮；设置界面保留置顶和最小化。关闭按钮收起窗口，后台继续统计，通过托盘或原来的快捷键恢复；托盘菜单「退出」才完全停止。

首次迁移将采集和额度提供方收敛到 Codex，默认关闭插件、Discord、重置预测及额外悬浮面板。主视图优先成员/设备，订阅列表和插件入口隐藏；采集来源、主题、窗口和诊断仍可在高级设置中查看。保留原数据与已有凭证，不改变设备 ID 或原始历史。未删除其他提供方的底层实现，以便兼容旧存档及将来合并上游。

## 构建与更新

专用构建入口为 `scripts/duo-builder.config.js`，Mac Apple Silicon 生成 ZIP，Windows x64 生成 NSIS 安装版和便携版。保留原版玻璃依赖及 Windows Dock 底层，不打包 macOS 原生 Widget 扩展。Linux、Mac Intel 和 iOS Widget 的原入口保留但不作为双人版发布目标。

更新检查、下载与反馈入口指向 `mrxiuer/token-monitor`。首版禁用应用内自动安装，手动下载安装同一 fork 的包。Mac 使用 ad-hoc 签名且没有公证，Windows 没有发行证书；不复用或声称拥有上游签名。安装覆盖前应退出旧客户端，安装后保留原来的数据目录和设置。

Node Hub 新字段见 [API](API.md#duo-members-and-quota-cycles)。本版不为 Cloudflare Worker 或 iCloud 实现成员/周期配置服务，保留这些兼容代码并不表示它们支持双人版功能。升级 ECS 时备份数据和服务配置，使用独立版本目录切换，验证后保留回退路径。
